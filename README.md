# 🐻 California DMV Driver's Knowledge Practice Test & Web App

An interactive, responsive web application and PWA designed to help drivers study and pass the **California DMV Written Knowledge Test**.

![CA DMV Practice Test](icons/icon-192.png)

## 🌟 Key Features

- **120 Comprehensive Questions**: Official California Driver Handbook questions covering:
  - 🚦 **Traffic Signs & Signals**
  - 🛣️ **Rules of the Road**
  - 🚗 **Safe Driving & Defensive Tactics**
  - 🅿️ **Parking & Curb Colors**
  - 🚶 **Right of Way & Pedestrians**
  - ⚠️ **Emergency Procedures & Skid Recovery**
- **🎨 Visual Diagrams & Illustrations**: High-resolution vector diagrams for every single question (signs, lane markings, wheel curb angles, following distances).
- **⏱️ Dual Test Configurations**:
  - **Adult (18+)**: 36 questions • 30 to pass (83%)
  - **Minor (Under 18)**: 46 questions • 38 to pass (83%)
- **🎯 Practice & Timed Exam Modes**: Study by specific categories or take a simulated timed DMV exam.
- **📖 120-Question Searchable Study Bank**: Full visual handbook review with instant search and filter pills.
- **🖨️ Printable Study Sheet**: Clean print-optimized layout for paper study or PDF export.
- **⌨️ Keyboard Shortcuts**: Fast desktop practice with `1-4` / `A-D` keys and `Enter` for next.
- **🌙 Light & Dark Mode**: Built-in theme switcher with persistence.
- **📱 PWA & Offline Support**: Installable on iPhone/Android home screens and works 100% offline.

## 🚀 Live Demo / GitHub Pages

To enable free web hosting on GitHub Pages:
1. Go to your repository **Settings** → **Pages**.
2. Under **Build and deployment** → **Branch**, select `main` and root `/`.
3. Click **Save** — GitHub will generate a live URL!

## 💻 Running Locally

### Option 1: Open Directly
Simply open `index.html` in any modern web browser (Chrome, Safari, Edge, Firefox).

### Option 2: Run with Local Server (PowerShell)
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then open [http://localhost:8080](http://localhost:8080).
